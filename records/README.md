# Built-in records

Put these files here and they appear in the record crate, in this order:

| File | Shows as |
| --- | --- |
| `desingerica-folkicc.mp3` | Desingerica – Folkicc |
| `sinan-sakic-ej-otkad-sam-se-rodio.mp3` | Sinan Sakić – Ej, otkad sam se rodio |
| `bejbi-motorola-smuti.mp3` | Bejbi Motorola – Smuti |
| `sta-sam-jeo.mp3` | Šta sam jeo |

Missing files are skipped. The list lives in `BUILT_IN` near the bottom of `main.js`.
